# RustForge MVP

- [x] Los usuarios pueden registrarse, iniciar sesión y cerrar sesión.
- [x] El sistema distingue roles `admin`, `moderator` y `user`, y bloquea cuentas baneadas.
- [x] La portada muestra novedades del cliente Rust y categorías/subcategorías.
- [x] Los usuarios autenticados pueden crear posts, comentarios y reportes de seguridad con una imagen opcional.
- [x] Los posts pueden marcarse como cerrados y los reportes se identifican como seguridad.
- [x] El perfil muestra insignias y la administración puede asignarlas.
- [x] El panel admin/moderador permite desactivar el chat, banear usuarios, cerrar posts y moderar contenido.
- [x] El panel admin permite crear categorías y subcategorías.
- [x] El proyecto incluye esquema MySQL, Docker Compose, variables de entorno y guía de instalación.
